# Changelog — Ataraxia (Coach Integral de Fitness, Nutrición y Rendimiento Estoico)

Todas las versiones notables de este proyecto se documentan en este archivo.
El formato se adhiere a [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/) y se adhiere a [Semantic Versioning](https://semver.org/lang/es/).

---

## [2.9.1] - 2026-10-12
### Añadido
- Módulo centralizado de logging seguro (`logger.ts`) con prevención activa de polución de consola en producción.
- Soporte accesible `a11y` (`id` y `aria-label`) para selectores de carga de archivos fotográficos en web (`transformation.tsx`).
- Reseteo canónico de CSS `:-webkit-autofill` en modo oscuro OLED (`global.css`) según el estándar Form Shield.

### Optimizado
- Gobernanza y Data Room M&A alineados al estándar institucional de inversión V-GUARD.
- Eliminación de llamadas de depuración residuales en runtime nativo y web.

---

## [2.9.0] - 2026-10-10
### Añadido
- Suite de pruebas unitarias y de integración dinámica (45 tests unitarios verificados al 100% en Node.js Test Runner).
- Desacoplamiento limpio de submódulos y estabilización de dependencias en React Native / Expo.
- Validación biomecánica de cadencia (ACSM) y filtro anti-vehículo en podómetro NEAT.

---

## [2.8.0] - 2026-09-25
### Añadido
- Motor de Mentoría Estoica con arquetipos duales (Mentor Sabio, Comandante Espartano y Fisiólogo Biohacker).
- Escáner biométrico de pulso cardíaco PPG cromático en tiempo real con soporte web y móvil.
- Sistema de evaluación del Ciclo de 30 Días con cálculo de virtudes cardinales.
